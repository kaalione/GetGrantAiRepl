## Uppgift

Tre saker ska åtgärdas i GetGrant.ai:

1. **Standardfilter: Visa bara relevanta bidrag per användare**
2. **Vinnova: Visa bara öppna/kommande bidrag som default**
3. **Kör AI eligibility extraction-pipelinen på alla 1 165 grants med ostrukturerade eligibility_criteria**

---

### 1. STANDARDFILTER — Visa bara matchande bidrag

**Problem:** EU F&T-bidrag dominerar (783 av 1 404 = 56%), men de flesta är irrelevanta för den enskilde användaren. Tanken är att bara visa bidrag som matchar användarens företagsprofil.

**Åtgärd:**
- På grant listing/browse-sidan: om användaren är inloggad och har en företagsprofil, visa **BARA** grants som matchar deras profil som default
- Lägg till en tydlig toggle/knapp: "Visa alla bidrag" / "Visa matchande bidrag" (default = matchande)
- Om användaren INTE har en profil, visa alla bidrag men med en banner: "Skapa en företagsprofil för att se bidrag som passar ditt företag"
- Sorteringsordning för matchande: match_score descending, sedan deadline ascending

**Frontend-ändringar:**
- Grants browse page: Lägg till filter-state `showOnlyMatching: boolean` (default true om profil finns)
- Visa filter som pill/toggle ovanför listan
- Uppdatera API-anropet till att inkludera `?matchProfile=true` parameter

**Backend-ändringar:**
- I grant listing endpoint: om `matchProfile=true` och användaren har profil, filtrera grants baserat på eligibility_criteria match mot company_profile
- Fallback: om structured eligibility_criteria saknas, visa bidraget ändå (exkludera inte pga saknad data)

### 2. VINNOVA — Visa bara öppna/kommande som default

**Problem:** Vinnova har 361 grants totalt men bara ~50 öppna. Stängda bidrag förvirrar användare.

**Åtgärd:**
- I alla grant listings: default status-filter = `open` och `upcoming` (inte `closed`)
- Lägg till synlig statusfilter med options: "Öppna" (default), "Kommande", "Stängda", "Alla"
- Stängda bidrag ska kunna visas men med tydlig visuell indikation: grå bakgrund, badge "Stängd — kan öppna igen", och nedsorteras i listan
- Detta gäller ALLA sources, inte bara Vinnova

**SQL-logik:**
```sql
-- Default query (öppna + kommande)
WHERE status IN ('open', 'upcoming')
ORDER BY 
  CASE WHEN status = 'open' THEN 0 ELSE 1 END,
  deadline ASC NULLS LAST;

-- Om användaren väljer "Alla":
ORDER BY 
  CASE WHEN status = 'open' THEN 0 
       WHEN status = 'upcoming' THEN 1
       WHEN status = 'closed' THEN 2 END,
  deadline ASC NULLS LAST;
```

**Frontend:**
- Lägg till StatusFilter-komponent med chips: Öppna ✓ | Kommande ✓ | Stängda ○ | Alla
- Default: Öppna + Kommande ikryssade
- Stängda grants renderas med `opacity-60` och en "Stängd"-badge

### 3. KÖR AI ELIGIBILITY EXTRACTION

**Problem:** 1 165 grants har ostrukturerade (raw text) eligibility_criteria. Inga har körts genom AI-extraktionspipelinen ännu. Utan strukturerad data fungerar varken matchning eller eligibility roadmap.

**Befintligt system:** Det finns redan en eligibilityExtractor-service i koden som:
- Tar grant-beskrivning + eligibility text
- Skickar till Claude API (claude-sonnet-4-5-20250929)
- Returnerar strukturerad JSON med: company_types, company_sizes, geography, sectors, collaboration_required, funding_details, etc.
- Sparar resultatet i grants-tabellens eligibility_criteria-kolumn som JSONB

**Åtgärd:**
1. Verifiera att eligibilityExtractor.ts finns och fungerar — testa med 1 grant först
2. Kör sedan extraction på ALLA öppna grants (prioritera open > upcoming > closed)
3. Kör i batches: 3 grants per batch, 15 sekunder delay mellan batches (respektera rate limits)
4. Max 50 grants per cron-körning, resten körs nästa gång
5. Logga resultat: processed, successful, failed, skipped

**Kör denna pipeline:**
```typescript
await processAllGrants({
  batchSize: 3,
  delayBetweenBatchesMs: 15000,
  onlyOpen: true,
  forceReprocess: false,
  maxGrants: 50
});
```

6. Integrera i cron — kör extraction dagligen EFTER scraping (scraping 08:00, extraction 09:00)
7. Skapa admin-endpoint för manuell körning: POST /api/admin/extract-eligibility
8. Skapa status-endpoint: GET /api/admin/eligibility-status som returnerar:
   - Totalt antal grants
   - Antal med structured criteria
   - Antal med unstructured criteria
   - Antal utan criteria
   - Senaste körning timestamp

**Efter extraction — uppdatera matchning:**
- Uppdatera grant matching-logiken att använda structured eligibility_criteria JSONB-data
- Matcha mot company_profile: company_type, size, region, sector
- Beräkna match_score 0-100 baserat på hur många kriterier som matchar
- Grants utan structured criteria: ge neutral score (50) — exkludera inte

### Verifiering

Kör dessa queries efter implementation:
```sql
-- Kontrollera eligibility extraction status
SELECT 
  COUNT(*) as total,
  COUNT(*) FILTER (WHERE eligibility_criteria IS NOT NULL 
    AND eligibility_criteria::text NOT IN ('null', '{}', '""')
    AND eligibility_criteria::jsonb ? 'company_types') as structured,
  COUNT(*) FILTER (WHERE eligibility_criteria IS NOT NULL 
    AND eligibility_criteria::text NOT IN ('null', '{}', '""')
    AND NOT (eligibility_criteria::jsonb ? 'company_types')) as unstructured,
  COUNT(*) FILTER (WHERE eligibility_criteria IS NULL 
    OR eligibility_criteria::text IN ('null', '{}', '""')) as missing
FROM grants;

-- Kontrollera status-fördelning
SELECT status, COUNT(*) FROM grants GROUP BY status ORDER BY COUNT(*) DESC;

-- Kontrollera Vinnova specifikt
SELECT status, COUNT(*) FROM grants 
WHERE source_name ILIKE '%vinnova%' 
GROUP BY status;
```
