
FIX 02  Set correct default score for grants with no eligibility data
Root cause
When a grant has no structured_eligibility (or eligibility with confidence_score < 0.3), the fallback matching gives maximum points for every criterion because there is nothing to fail against. This means a law firm scores 100 on a Vinnova deeptech grant just because Vinnova hasn't described who can't apply. The fix is a single number change: default score = 35, not 100.
 
Files to change: client/src/lib/matching.ts  ·  server/services/matching.ts (if exists)
