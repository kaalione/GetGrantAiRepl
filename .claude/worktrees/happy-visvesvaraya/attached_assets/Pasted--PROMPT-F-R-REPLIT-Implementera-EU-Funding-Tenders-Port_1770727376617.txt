## EU F&T PORTAL API — FULL SPECIFIKATION

### Bas-endpoint

```
POST https://api.tech.ec.europa.eu/search-api/prod/rest/search?apiKey=SEDIA&text=***
```

- **Metod:** POST
- **Content-Type:** multipart/form-data
- **Ingen autentisering** — `apiKey=SEDIA` är publik
- **Paginering:** `pageNumber` och `pageSize` som query-parametrar

### Hur man skickar requests

Queryn skickas som **form-data** (inte JSON body), med key `query` och värdet som JSON-sträng. Lägg även till `languages` = `en`.

```python
import requests, json

URL = "https://api.tech.ec.europa.eu/search-api/prod/rest/search"

params = {
    "apiKey": "SEDIA",
    "text": "***",
    "pageNumber": 1,
    "pageSize": 50
}

query = {
    "bool": {
        "must": [
            {"terms": {"type": ["1"]}},             # 1 = Grants (inte tenders)
            {"terms": {"status": ["31094501", "31094502"]}}  # Open + Forthcoming
        ]
    }
}

files = {
    "query": (None, json.dumps(query)),
    "languages": (None, "en")
}

response = requests.post(URL, params=params, files=files)
data = response.json()
```

### Referenskoder

**Type-koder (vad vi söker):**
- `"0"` = Call for Tenders (SKIPPA)
- `"1"` = Call for Proposals / Grants (VI VILL HA DESSA)
- `"2"` = Call for Expression of Interest
- `"8"` = Övrigt

**Status-koder:**
- `"31094501"` = Open (aktiva nu)
- `"31094502"` = Forthcoming (öppnar snart — viktigt att inkludera!)
- `"31094503"` = Closed (skippa vid initial import)

**Program-koder (frameworkProgramme):**
- `"43108390"` = Horizon Europe
- `"43353764"` = Erasmus+
- Övriga koder kan hämtas via Facet API (se nedan)

### Filtrerings-exempel

**Alla öppna grants:**
```json
{"bool":{"must":[{"terms":{"type":["1"]}},{"terms":{"status":["31094501","31094502"]}}]}}
```

**Bara Horizon Europe:**
```json
{"bool":{"must":[{"terms":{"type":["1"]}},{"terms":{"status":["31094501","31094502"]}},{"term":{"programmePeriod":"2021 - 2027"}},{"terms":{"frameworkProgramme":["43108390"]}}]}}
```

**Med specifik call:**
```json
{"bool":{"must":[{"terms":{"type":["1"]}},{"term":{"callIdentifier":"HORIZON-INFRA-2021-EOSC-01"}}]}}
```

### Facet API (för att mappa referenskoder till namn)

```
POST https://api.tech.ec.europa.eu/search-api/prod/rest/facet?apiKey=SEDIA&text=***
```
Samma query-body. Returnerar facets med kod→namn-mappningar för program, status, etc.

### Topic Details (detaljer om en specifik utlysning)

```
POST https://api.tech.ec.europa.eu/search-api/prod/rest/search?apiKey=SEDIA&text="HORIZON-CL3-2022-BM-01-01"
```
Sök med topic-identifier inom citattecken.

### Grant Updates (inkrementella uppdateringar)

```json
{"bool":{"must":[{"terms":{"type":["6"]}}]}}
```
Type `"6"` = Grant Updates. Filtrera på `frameworkProgramme` för specifikt program.

## VAD DU SKA BYGGA

### 1. `scrapers/sources/eu_funding_tenders.py`

En klass `EUFundingTendersClient` som:

- Hämtar alla öppna + forthcoming grants via API:et
- Hanterar paginering automatiskt (loop tills alla sidor är hämtade)
- Parsear varje resultat till samma format som övriga scrapers (matchar db-schemat)
- Rate-limitar (1 request per sekund)
- Loggar antal hämtade, nya, uppdaterade

**Mappning API → GetGrant databas:**

| API-fält (i metadata) | DB-fält | Notering |
|---|---|---|
| `identifier[0]` | `external_id` | Unikt ID, t.ex. `HORIZON-CL4-2026-01-MAT-01` |
| `title[0]` | `title` | Fullständig titel |
| `description[0]` eller `content` (top-level) | `description` | |
| `url` (top-level) | `url` | Direktlänk till topic-sida |
| `startDate[0]` | `start_date` | ISO-format, parse till datetime |
| `deadlineDate[0]` eller `closingDate[0]` | `deadline` | Viktigaste datumfältet |
| `overallBudget[0]` | `amount_max` | Float, kan vara None |
| `status[0]` | `status` | Mappa: 31094501→"open", 31094502→"forthcoming" |
| `programDescription[0]` | `source` | T.ex. "Horizon Europe (HORIZON)" |
| `programAbbreviation[0]` | `source_short` | T.ex. "HORIZON" |
| `typeOfAction[0]` | `grant_type` | T.ex. "Innovation Actions" |
| `keywords` | `tags` | Array av strängar |
| `callIdentifier[0]` | `call_id` | Gruppering |
| `crossCuttingPriorities` | `categories` | Tematiska områden |

### 2. Integrera i `main.py`

Lägg till EU-scrapern så den körs tillsammans med Vinnova och Tillväxtverket.

### 3. Deduplicering

Bidrag från EU-portalen kan dyka upp i andra källor (Eufonder.se, Verksamt.se). Implementera:
- **Primär:** Matcha på `external_id` (topic identifier)
- **Sekundär:** URL-matchning
- **Fallback:** Fuzzy title matching (om vi lägger till andra EU-källor senare)

### 4. Felhantering

- API:et kan returnera 5xx vid hög last → retry med exponential backoff
- Tomma metadata-fält → hantera gracefully med defaults
- Rate limiting → max 1 req/sekund, respektera 429-svar

## VIKTIGA DETALJER

1. **Hämta INTE closed grants** vid initial import — bara open + forthcoming
2. **Alla metadata-fält är arrays** — ta alltid `[0]`, kolla att arrayen inte är tom
3. **`url`-fältet** på top-level kan vara "NA" för vissa resultat — bygg URL från identifier istället: `https://ec.europa.eu/info/funding-tenders/opportunities/portal/screen/opportunities/topic-details/{identifier}`
4. **Budget-fält** (`overallBudget`) finns inte alltid — gör det optional
5. **Programme-period** bör filtreras till `"2021 - 2027"` (nuvarande period)
6. **`text=***`** i URL:en är wildcard-sökning (returnerar allt som matchar query-filtren)
7. **Paginering:** Default `pageSize` är 10 — sätt den till 50 för effektivitet. Loopa med ökande `pageNumber` tills `len(results) < pageSize` eller total nådd.
