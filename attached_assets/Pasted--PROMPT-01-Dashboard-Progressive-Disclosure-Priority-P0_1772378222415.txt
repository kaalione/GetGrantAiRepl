What & Why
The dashboard currently displays 9+ sections simultaneously (stats, progress tracker, profile banner, upgrade prompt, two deadline alert cards, top matches, eligibility dashboard, active projects, active agreements). First-time users are overwhelmed before they understand the product. Fix: show a simplified 'Getting Started' view for users with <40% profile completion and <2 grant interactions, and progressively unlock dashboard sections as they engage. Use the existing user_progress table to drive this logic.
📋  Replit Prompt — copy this exactly
 
In Dashboard.tsx, fetch user_progress and profile completion score.
 
Create a NEW component DashboardNewUser.tsx that shows ONLY:
 1. A welcome hero with the user's company name
 2. The progress tracker (prominent, full-width)
 3. The profile completion banner if score < 90%
 4. A single 'Your first grant matches' card (top 3 grants)
 5. A 'What happens next' explainer (3 icon steps)
 
In Dashboard.tsx add a conditional:
 const isNewUser = profileCompletion < 40 && totalInteractions < 2;
 if (isNewUser) return <DashboardNewUser />;
 
For returning users (isNewUser === false), keep existing sections
but reorder them in this priority sequence:
 1. Red/amber deadline alerts (if any grants expiring <=7 days)
 2. Stats cards row
 3. Top matches
 4. Progress tracker (compact mode)
 5. Eligibility dashboard
 6. Active projects
 7. Active agreements
 8. Upgrade prompt (last, least urgent)
 
Remove the separate 'urgent grants' card — merge into deadline alerts.
 
Add a small 'Customise dashboard' link at bottom (no-op for now,
just shows a toast: 'Personalised dashboard coming soon').
✅  Verification steps

2. Complete profile to 90%+. Confirm full dashboard unlocks.
3. Confirm deadline alert cards still appear correctly for returning users.
