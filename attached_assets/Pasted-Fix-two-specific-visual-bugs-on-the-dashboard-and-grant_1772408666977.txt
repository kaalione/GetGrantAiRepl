BUG 1 — Dashboard "Deadline snart" widget shows irrelevant grants.

In client/src/pages/dashboard.tsx, the deadline widgets ("Deadline inom 7 dagar" 
and "Deadline snart") are built from deadlinesNext7Days which comes from the 
stats API and contains minimal data — not enough for match score filtering.

Replace BOTH deadline sections with data built from the already-loaded 
grants array. Here is the exact replacement logic:

  const urgentDeadlineGrants = useMemo(() => {
    const grantsArray = Array.isArray(grants) ? grants : [];
    const today = new Date();
    today.setHours(0, 0, 0, 0);
    
    return grantsArray
      .filter((g: any) => {
        if (!g.deadline) return false;
        const deadline = new Date(g.deadline);
        const daysLeft = Math.ceil(
          (deadline.getTime() - today.getTime()) / (1000 * 60 * 60 * 24)
        );
        return daysLeft >= 0 && daysLeft <= 14;
      })
      .map((g: any) => {
        const scoreResult = company 
          ? calculateMatchScore(company, g) 
          : null;
        return { ...g, matchScore: scoreResult?.score ?? 0 };
      })
      .filter((g: any) => !company || g.matchScore >= 25)
      .sort((a: any, b: any) => 
        new Date(a.deadline).getTime() - new Date(b.deadline).getTime()
      )
      .slice(0, 5);
  }, [grants, company]);

Then replace the existing deadline widget JSX to use urgentDeadlineGrants 
instead of deadlinesNext7Days / urgentGrants.

Note: calculateMatchScore takes (company, grant) in that order — 
company first, grant second.

BUG 2 — Sort order in /bidrag puts "1 dag kvar" grants above higher-scored grants.

In client/src/pages/grants.tsx (or wherever sortedGrants is computed),
ensure the sort is STRICTLY score-first:

  .sort((a, b) => {
    const scoreA = a.matchScore ?? 0;
    const scoreB = b.matchScore ?? 0;
    if (scoreB !== scoreA) return scoreB - scoreA; // score DESC always first
    // Only use deadline as tiebreaker for identical scores
    if (!a.deadline && !b.deadline) return 0;
    if (!a.deadline) return 1;
    if (!b.deadline) return -1;
    return new Date(a.deadline).getTime() - new Date(b.deadline).getTime();
  })
