7. Verifiera att antal bidrag är rimligt

**Efter fix — kör deduplicering:**
```sql
-- Hitta potentiella dubbletter efter fix
SELECT title, source_name, COUNT(*) 
FROM grants
```

### IMPLEMENTATION FÖR VARJE NY KÄLLA

Följ befintlig scraper-arkitektur. Varje ny scraper ska:

1. **Ärva från BaseScraper** (eller motsvarande basklass i projektet)
2. **Returnera grants i standardformat:**
```typescript
{
  title: string;
  description: string;
  source_url: string;        // URL till bidraget
  source_name: string;       // T.ex. "Interreg ÖKS"
  status: 'open' | 'upcoming' | 'closed';
  deadline: Date | null;
  amount_min: number | null;
  amount_max: number | null;
  amount_description: string | null;
  eligibility_criteria: string | null;   // Raw text — AI extraction körs separat
  grant_type: string;        // "grant", "loan", "guarantee", etc.
  funding_body: string;      // T.ex. "Interreg", "Forte"
  application_url: string | null;
}
```
3. **Använda upsert via source_url** som unique key (deduplicering nivå 1)
4. **Respektera rate limits:** max 1 request per 2 sekunder, respektera robots.txt
5. **Logga:** antal nya, uppdaterade, oförändrade grants per körning
6. **Registrera i scraper-config** så den körs automatiskt i cron

### Verifiering efter implementation
```sql
-- Kontrollera nya sources
SELECT source_name, COUNT(*), 
  COUNT(*) FILTER (WHERE status = 'open') as open,
  COUNT(*) FILTER (WHERE status = 'upcoming') as upcoming,
  COUNT(*) FILTER (WHERE status = 'closed') as closed
FROM grants 
GROUP BY source_name 
ORDER BY COUNT(*) DESC;

-- Total
SELECT COUNT(*) as total_grants FROM grants;

-- Kontrollera deduplicering
SELECT title, COUNT(*) as dupes
FROM grants 
GROUP BY title 
HAVING COUNT(*) > 2
ORDER BY dupes DESC
LIMIT 20;
```
