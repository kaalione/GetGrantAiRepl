Team Collaboration
Add team collaboration features so multiple people at a company can work together 
on grant applications — invite colleagues, see who's editing, leave comments, 
and track changes.

## Overview
Companies rarely apply for grants alone — a CEO writes the vision, a CFO handles 
the budget section, a technical lead writes the project description. This feature 
enables that workflow directly in GetGrant.ai, inspired by GrantPilot.se's 
collaboration features and Cogrant's team workspace.

## Backend: New API endpoints

Create `server/routes/collaboration.ts`:

### Invite management
POST /api/applications/:id/collaborators/invite
Body: { email: string, role: 'editor' | 'viewer' | 'commenter' }

Generate secure invite token (crypto.randomUUID())
Store in application_collaborators with status: 'pending'
Send invite email via Resend
Response: { inviteId, email, role, expiresAt }

GET /api/applications/:id/collaborators

List all collaborators with their roles and status
Response: [{ userId, email, name, role, status, joinedAt }]

PUT /api/applications/:id/collaborators/:userId/role
Body: { role: 'editor' | 'viewer' | 'commenter' }

Only application owner can change roles

DELETE /api/applications/:id/collaborators/:userId

Remove a collaborator (owner only, or self-removal)

GET /api/invites/:token/accept

Accept an invite link (user clicks link in email)
If user not logged in: redirect to login with returnUrl
If user logged in: accept invite, redirect to application
Update status to 'accepted', set joinedAt


### Comments
GET /api/applications/:id/comments
Query: ?sectionKey=project_description (optional filter)
Response: comments with author info, nested threads, resolved status
POST /api/applications/:id/comments
Body: { sectionKey?: string, content: string, parentId?: string }
Response: created comment with author info
PUT /api/comments/:commentId/resolve

Mark comment as resolved (only editor/owner)

DELETE /api/comments/:commentId

Delete own comment only


### Section history
GET /api/applications/:id/sections/:sectionKey/history
Response: last 20 versions with editor name and timestamp
POST /api/applications/:id/sections/:sectionKey/restore/:historyId

Restore a previous version (saves current as new history entry first)


### Real-time presence (WebSocket)

Use the existing WebSocket setup if available, otherwise add:
```typescript
// server/websocket/collaboration.ts
import { WebSocketServer } from 'ws';

const rooms = new Map<string, Set<WebSocket>>();

// Events to handle:
// client → server: { type: 'join', applicationId, userId, userName }
// client → server: { type: 'section_focus', sectionKey }
// client → server: { type: 'typing', sectionKey, cursorPosition }
// client → server: { type: 'leave' }

// server → client: { type: 'presence_update', users: PresenceUser[] }
// server → client: { type: 'section_updated', sectionKey, editedBy, updatedAt }
// server → client: { type: 'comment_added', comment }

export function setupCollaborationWS(wss: WebSocketServer) {
  wss.on('connection', (ws, req) => {
    let applicationId: string;
    let userId: string;
    
    ws.on('message', (data) => {
      const event = JSON.parse(data.toString());
      
      if (event.type === 'join') {
        applicationId = event.applicationId;
        userId = event.userId;
        
        // Add to room
        if (!rooms.has(applicationId)) rooms.set(applicationId, new Set());
        rooms.get(applicationId)!.add(ws);
        
        // Broadcast presence update to all in room
        broadcastToRoom(applicationId, {
          type: 'presence_update',
          users: getPresenceUsers(applicationId)
        });
      }
      
      if (event.type === 'section_focus') {
        updatePresence(applicationId, userId, event.sectionKey);
        broadcastToRoom(applicationId, {
          type: 'presence_update',
          users: getPresenceUsers(applicationId)
        }, ws); // exclude sender
      }
    });
    
    ws.on('close', () => {
      if (applicationId) {
        rooms.get(applicationId)?.delete(ws);
        broadcastToRoom(applicationId, {
          type: 'presence_update',
          users: getPresenceUsers(applicationId)
        });
      }
    });
  });
}
```

## Permission middleware
```typescript
// server/middleware/collaborationAuth.ts
export async function requireApplicationAccess(
  req: Request, res: Response, next: NextFunction,
  requiredRole: 'owner' | 'editor' | 'viewer' | 'commenter' = 'viewer'
) {
  const { id: applicationId } = req.params;
  const userId = req.user?.id;
  
  const collaborator = await db.query.applicationCollaborators.findFirst({
    where: and(
      eq(applicationCollaborators.applicationId, applicationId),
      eq(applicationCollaborators.userId, userId),
      eq(applicationCollaborators.status, 'accepted')
    )
  });
  
  // Check owner access
  const application = await db.query.applications.findFirst({
    where: eq(applications.id, applicationId)
  });
  
  if (application?.userId === userId) return next(); // owner always has access
  if (!collaborator) return res.status(403).json({ error: 'Access denied' });
  
  const roleHierarchy = { viewer: 0, commenter: 1, editor: 2, owner: 3 };
  if (roleHierarchy[collaborator.role] < roleHierarchy[requiredRole]) {
    return res.status(403).json({ error: 'Insufficient permissions' });
  }
  
  next();
}
```
