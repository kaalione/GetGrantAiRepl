Run extraction on all unextracted open grants
With the improved prompt in place and the admin UI ready, run the extraction pipeline on all grants that have never been extracted. Then immediately queue a re-extraction pass on all low-confidence results. Do this in batches of 50 with a 2-second delay between grants to respect rate limits.
 
1
Before starting — confirm the cron endpoint works
Call:  POST /api/cron/extract-eligibility
Body:  { "batchSize": 5, "maxGrants": 5, "onlyMissing": true }
Expected response: { processed: 5, succeeded: 4-5, failed: 0-1 }
Open one of the processed grants in the DB and confirm structured_eligibility
is now a JSONB object with confidence_score >= 0.3.
If this works, proceed to the full run.
 
2
Run extraction on all unextracted grants
Call:  POST /api/cron/extract-eligibility
Body:  { "batchSize": 50, "maxGrants": 2000, "onlyMissing": true, "delayMs": 2000 }
This will take 30–90 minutes depending on grant count.
The endpoint should respond immediately with { started: true } and run in background.
Monitor progress via: GET /api/admin/eligibility/coverage (refresh every 5 min).
Do not run other extraction jobs in parallel.
 
3
Re-run low-confidence extractions with the improved prompt
Once the first pass completes (coverage stops increasing), run a second pass:
Call:  POST /api/admin/eligibility/reextract-low-confidence
Body:  { "threshold": 0.3, "maxGrants": 300 }
This retries grants where the first extraction returned confidence < 0.3.
Many of these will still return low confidence — that's expected for grants
with genuinely sparse descriptions. Accept them as 'cannot extract further'.
 
4
Verify final coverage and run the matching test
Run the coverage SQL query again (from the Diagnostic section).
Target: overall pct_good >= 65% of open grants.
Then run: npx tsx scripts/test-matching-quality.ts
Check C (score spread) should now pass for at least 5/10 companies.
If C8 (law firm) top score has crept above 60, a low-confidence grant
is scoring on keyword matches — check its structured_eligibility sectors field.

EU Funding & Tenders — special handling
The EU F&T portal API returns short summaries, not the full call text.
For grants from this source where confidence_score < 0.4:
 1. Store the portal URL in the grant record
 2. When a user clicks 'Run AI analysis' on the grant detail page,
    fetch the full page text from the URL before calling the extraction prompt.
 3. This gives the AI full eligibility text and should push confidence to 0.6+.
This is on-demand extraction, not batch — it scales without API cost.
