Build an AI-powered grant application writing module for GetGrant.ai.

## Overview
Users select a grant, answer a few questions about their project, and the AI generates 
a complete draft application tailored to that specific grant's requirements and 
evaluation criteria.

## Backend: New API endpoints

Create `server/routes/applications.ts` with these endpoints:

### POST /api/applications/generate
Generate a draft application for a specific grant.

Request body:
{
  grantId: string,
  companyProfile: {
    name: string,
    description: string,
    sector: string,
    employees: number,
    revenue?: number,
    founded?: number,
    region: string
  },
  projectDescription: string,      // 200-1000 chars, what they want to do
  projectGoals: string,             // expected outcomes
  projectBudget: number,            // total project budget in SEK
  requestedAmount: number,          // amount applying for
  previousExperience?: string       // relevant prior work
}

Response:
{
  applicationId: string,
  grantId: string,
  grantTitle: string,
  sections: [
    {
      sectionKey: string,           // e.g. "project_description"
      sectionTitle: string,         // e.g. "Projektbeskrivning"
      content: string,              // AI-generated text
      wordCount: number,
      maxWords?: number,            // from grant template if known
      evaluationCriteria?: string   // what judges look for in this section
    }
  ],
  overallScore?: number,            // estimated fit score 0-100
  warnings: string[],               // e.g. "Budget exceeds maximum grant amount"
  generatedAt: string
}

### GET /api/applications/:id
Retrieve a saved application draft.

### PUT /api/applications/:id/section/:sectionKey
Update a specific section (user edits).

Request body: { content: string }

### POST /api/applications/:id/regenerate-section
Regenerate a specific section with new instructions.

Request body: { sectionKey: string, instructions: string }

### GET /api/applications/templates/:grantSource
Get the application template for a specific grant source.

```typescript
export async function generateApplication(
  grant: Grant,
  companyProfile: CompanyProfile,
  projectData: ProjectData
): Promise<GeneratedApplication> {
  const client = new Anthropic();
  
  // Determine which template to use based on grant source
  const sourceKey = grant.source.toLowerCase();
  const template = GRANT_TEMPLATES[sourceKey] || GRANT_TEMPLATES.generic;
  
  const sections = [];
  
  // Generate each section with a targeted prompt
  for (const sectionTemplate of template.sections) {
    const prompt = buildSectionPrompt(
      grant, 
      companyProfile, 
      projectData, 
      sectionTemplate
    );
    
    const response = await client.messages.create({
      model: 'claude-opus-4-5',
      max_tokens: 1500,
      messages: [{ role: 'user', content: prompt }]
    });
    
    const content = response.content[0].type === 'text' 
      ? response.content[0].text 
      : '';
    
    sections.push({
      sectionKey: sectionTemplate.key,
      sectionTitle: sectionTemplate.title,
      content: content.trim(),
      wordCount: content.split(' ').length,
      maxWords: sectionTemplate.maxWords,
      evaluationCriteria: sectionTemplate.evaluationCriteria
    });
  }
  
  // Generate overall warnings
  const warnings = generateWarnings(grant, companyProfile, projectData);
  
  return { sections, warnings };
}

function buildSectionPrompt(
  grant: Grant,
  company: CompanyProfile, 
  project: ProjectData,
  section: SectionTemplate
): string {
  return `You are an expert Swedish grant application writer. Write the "${section.title}" 
section for a grant application.

GRANT INFORMATION:
- Grant: ${grant.title}
- Funder: ${grant.source}
- Grant description: ${grant.description}
- Max amount: ${grant.maxAmount ? `${grant.maxAmount} SEK` : 'Not specified'}
- Deadline: ${grant.deadline || 'Not specified'}

COMPANY INFORMATION:
- Company: ${company.name}
- Sector: ${company.sector}
- Description: ${company.description}
- Employees: ${company.employees}
- Region: ${company.region}
${company.revenue ? `- Annual revenue: ${company.revenue} SEK` : ''}

PROJECT INFORMATION:
- Project description: ${project.projectDescription}
- Goals: ${project.projectGoals}
- Total budget: ${project.projectBudget} SEK
- Requested amount: ${project.requestedAmount} SEK
${project.previousExperience ? `- Relevant experience: ${project.previousExperience}` : ''}

SECTION INSTRUCTIONS:
- Section to write: ${section.title}
- What this section should cover: ${section.description}
- Max length: ${section.maxWords || 500} words
- Evaluation criteria (what judges look for): ${section.evaluationCriteria}

WRITING REQUIREMENTS:
- Write in Swedish if the grant is from a Swedish agency (Vinnova, Tillväxtverket, 
  Energimyndigheten, etc.), otherwise write in English
- Be specific and use concrete numbers where possible
- Align the language with what grant evaluators want to see
- Do NOT use generic filler phrases — every sentence should add value
- Do NOT exceed the word limit
- Write in first person plural ("Vi planerar..." / "Our project will...")
- Output ONLY the section text, no headers or meta-commentary

Write the section now:`;
}
```

## Frontend: New page client/src/pages/apply.tsx

Create a 4-step wizard:

**Step 1 — Select grant**
- Show the grant the user clicked "Apply" from (pre-selected)
- Display grant summary: title, funder, deadline, max amount
- Show match score and why it matched (pulls from existing matching data)

**Step 2 — Company profile**
- Pre-fill from user's saved profile if available
- Fields: company name, description (textarea), sector (dropdown using 
  existing sector list), employees (number), annual revenue (optional), 
  region (dropdown), founded year (optional)
- "Save to profile" checkbox

**Step 3 — Project information**
- Project description (textarea, 200-1000 chars, live character count)
- Project goals (textarea, what will be achieved)
- Total project budget (SEK, number input)
- Requested amount (SEK, auto-validates against grant max)
- Previous relevant experience (optional textarea)

**Step 4 — Generated application**
- Show loading state: "Generating your application... this takes about 30 seconds"
- Animated progress with messages like "Analyzing grant criteria...", 
  "Writing project description...", "Reviewing for compliance..."
- Once generated, show each section as an editable card:
  - Section title
  - Word count / max words indicator (green if under, red if over)
  - Evaluation criteria shown as subtle hint text
  - Editable textarea with the AI content
  - "Regenerate this section" button (opens modal for custom instructions)
- Warnings banner at top if any (e.g. "Your requested amount exceeds the grant maximum")
- Bottom bar: "Copy all", "Download as PDF", "Download as Word (.docx)"

## Export functionality

Add `server/services/exportApplication.ts`:

**PDF export**: Use `pdfkit` npm package to generate a formatted PDF
**Word export**: Use `docx` npm package to generate a .docx file

Both exports should include:
- Header: Grant name, company name, generated date
- Each section with its title as a heading
- Page numbers
- Footer: "Generated by GetGrant.ai"
