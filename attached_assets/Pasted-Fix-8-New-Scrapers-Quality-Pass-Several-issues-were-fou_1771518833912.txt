🟡 FIX 4: EDF — Prevent duplicates with EU F&T scraper
The EDF scraper is a wrapper around the EU F&T scraper using programme ID 44181033. This creates a risk of the same grants appearing twice in the database — once from the full EU F&T run and once from the EDF wrapper.
Add this deduplication check in the EDF scraper:
python# In edf_scraper.py, after fetching grants, before upserting:
def deduplicate_against_eu_ft(self, grants: list) -> list:
    """Remove grants already stored by the EU F&T scraper to prevent duplicates."""
    existing_urls = self.db.get_grant_urls_by_source('eu_funding_tenders')
    deduped = [g for g in grants if g['source_url'] not in existing_urls]
    logger.info(f"EDF: {len(grants)} fetched, {len(deduped)} after dedup against EU F&T")
    return deduped
If get_grant_urls_by_source doesn't exist yet, add it to db.py:
