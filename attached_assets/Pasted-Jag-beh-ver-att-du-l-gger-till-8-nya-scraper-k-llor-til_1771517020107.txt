Jag behöver att du lägger till 8 nya scraper-källor till GetGrant.ai-plattformen.

KÄLLA 1 — EIT Knowledge & Innovation Communities (9 KICs i en scraper)
=================================================================
Alla 9 EIT KICs har utlysningssidor med liknande HTML-struktur. Bygg EN generisk 
EitKicScraper-klass som tar en config-lista och loopar över alla nio:

EIT_KICS = [
  { id: "eit-urban-mobility",    url: "https://www.eiturbanmobility.eu/call-for-proposals/",        label: "EIT Urban Mobility",     sector: "Transport/Mobilitet" },
  { id: "eit-manufacturing",     url: "https://eitmanufacturing.eu/what-we-offer/open-calls/",       label: "EIT Manufacturing",      sector: "Tillverkning/Industri" },
  { id: "eit-food",              url: "https://www.eitfood.eu/open-calls",                           label: "EIT Food",               sector: "Livsmedel/Agritech" },
  { id: "eit-health",            url: "https://eithealth.eu/programmes-projects/",                   label: "EIT Health",             sector: "Hälsa/Life Science" },
  { id: "eit-digital",           url: "https://www.eitdigital.eu/our-work/calls/",                   label: "EIT Digital",            sector: "Digitalt/AI" },
  { id: "eit-rawmaterials",      url: "https://eitrawmaterials.eu/funding-opportunities/",           label: "EIT RawMaterials",       sector: "Råmaterial/Gruvteknik" },
  { id: "eit-climate-kic",       url: "https://www.climate-kic.org/open-calls/",                     label: "EIT Climate-KIC",        sector: "Klimat/Hållbarhet" },
  { id: "eit-culture-creativity",url: "https://eitculture.eu/open-calls/",                           label: "EIT Culture & Creativity", sector: "Kultur/Kreativa industrier" },
  { id: "eit-innoenergy",        url: "https://www.eitinnoenergy.com/for-innovators/calls/",         label: "EIT InnoEnergy",         sector: "Energi/CleanTech" }
]

Teknik: BeautifulSoup (BS4). För varje KIC: scrapa titlar, beskrivningar, 
deadlines och belopp från utlysningssidan. Tagga source_id som t.ex. 
"eit-urban-mobility", sätt funding_type = "EU/EIT", geography = "EU/Sverige".

Notera: Sidornas HTML-struktur skiljer sig något åt per KIC. Bygg robusta 
fallback-selectors. Om en sida kräver JS-rendering, byt till Playwright för 
just den KIC:en. Logga vilken teknik som används per källa.

KÄLLA 5 — COST Actions (European Cooperation in Science and Technology)
=================================================================
Primär URL: https://www.cost.eu/funding/open-call-a-simple-one-step-application-process/
Öppna actions-databas: https://www.cost.eu/cost-actions/

Teknik: BS4 + eventuellt e-COST API om tillgängligt
source_id: "cost-actions"
funding_type: "EU/COST"
sector: "FoU/Nätverk/Tvärvetenskapligt"
geography: "EU/Sverige"

Scrapa TWÅ saker:
1. Öppna call för NYA actions (Open Call 2026 — ansökan öppnar sommar 2026, 
   deadline höst 2026). Budget: €125,000/år i 4 år per action.
2. Befintliga LÖPANDE COST Actions som fortfarande rekryterar nya 
   medlemmar — sök på https://e-cost.cost.eu/costActionSearch med status 
   "OPEN" eller via https://www.cost.eu/cost-actions/ filtrera på aktiva.
   
Notering: COST Actions är nätverksbidrag, inte projektbidrag. Tydliggör 
detta i funding_type och beskrivning. Inga direkta EU-pengar till organisationen, 
men möjlighet att delta i pan-europeiska FoU-nätverk med reseersättning etc.

GEMENSAMMA TEKNISKA KRAV FÖR ALLA 8 KÄLLOR
=================================================================

1. DATASTRUKTUR: Varje bidrag ska mappas till befintligt grant-schema:
   - title (str)
   - description (str, max 2000 tecken, svensk eller engelsk)
   - source_id (str, enligt ovan)
   - source_url (str, direktlänk till utlysningen)
   - funding_amount_min / funding_amount_max (int, EUR)
   - deadline (date eller null)
   - status: "open" | "upcoming" | "closed"
   - funding_type (str)
   - sector_tags (array of strings)
   - geography (str)
   - eligibility_notes (str, kortfattat om krav)
   - language: "en" (alla dessa källor är på engelska)

2. DEDUPLICERING: Använd befintlig 3-nivå dedup (URL-match → titel-similarity 
   → content hash). Dessa är EU-källor utan överlapp med svenska myndigheter, 
   men EDF kan överlappa med EU F&T Portal.

3. SCHEMALÄGGNING: Lägg till alla 8 scrapers i den befintliga 
   scheduler/cron-konfigurationen. Rekommenderad frekvens:
   - EIT KICs: varannan vecka (calls öppnar sällan)
   - CASSINI: månadsvis
   - IHI: varannan vecka (calls pågår månader)
   - Nordic Innovation: varannan vecka
   - COST Actions: månadsvis
   - NLnet/NGI Zero: varannan månad (matchar deras call-rytm)
   - NATO SPS: månadsvis
   - EDF: varannan vecka

4. FELHANTERING: Om en sida inte svarar eller HTML-strukturen förändrats, 
   logga felmeddelandet med source_id + timestamp + HTTP-kod och skicka 
   alert via befintligt monitoring-system. Markera INTE befintliga bidrag 
   som "closed" förrän 3 misslyckade scraping-försök i rad.

5. TAGGNING FÖR AI-MATCHNING: Lägg till följande sector_tags per källa 
   för att förbättra AI-matchningens precision:
   - EIT Urban Mobility: ["transport", "mobilitet", "stadsplanering", "elfordon"]
   - EIT Manufacturing: ["tillverkning", "industri", "automation", "AI"]
   - EIT Food: ["livsmedel", "agritech", "hållbart jordbruk", "matproduktion"]
   - EIT Health: ["hälsa", "life science", "medtech", "sjukvård"]
   - EIT Digital: ["digitalt", "AI", "cybersäkerhet", "deeptech"]
   - EIT RawMaterials: ["råmaterial", "gruvindustri", "cirkular ekonomi"]
   - EIT Climate-KIC: ["klimat", "hållbarhet", "cleantech", "CO2"]
   - EIT Culture & Creativity: ["kultur", "kreativa industrier", "media"]
   - EIT InnoEnergy: ["energi", "cleantech", "batterier", "vätgas"]
   - CASSINI: ["space tech", "satellit", "rymdfart", "geospatialt"]
   - IHI: ["hälsa", "life science", "pharma", "healthtech", "klinisk forskning"]
   - Nordic Innovation: ["nordisk", "hållbarhet", "innovation", "SMF"]
   - COST Actions: ["forskning", "nätverk", "akademi", "tvärvetenskapligt"]
   - NLnet/NGI Zero: ["open source", "privacy", "internet-infrastruktur", "FOSS"]
   - NATO SPS: ["cybersäkerhet", "försvar", "dual-use", "säkerhet"]
   - EDF: ["försvar", "dual-use", "säkerhetsteknik", "försvarstech"]

6. TESTNING: Efter implementation, kör varje scraper manuellt och 
   verifiera att minst 1 bidrag hämtas per källa. Logga antal hämtade 
   bidrag per körning. Om 0 bidrag returneras — flagga som ERROR, 
   inte silent success.

Rapportera tillbaka med: 
- Antal bidrag hämtade per källa vid första körning
- Eventuella JS-renderingsproblem (Playwright behövs)  
- HTML-strukturer som avviker från förväntad (fallback-selectors aktiverade)
- Totalt antal nya bidrag adderade till databasen
