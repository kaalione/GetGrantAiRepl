Two remaining issues after the last fix:

ISSUE 1 — Dashboard "Deadline snart" widget still shows irrelevant grants.

The widget in client/src/pages/dashboard.tsx shows Forskningsrådet grants 
(marine ecosystems, Norwegian language titles) for a Teknik & IT company.
The score >= 30 filter added previously is not working.

Debug by adding a console.log in the dashboard component:
  console.log("Deadline items before filter:", deadlineItems.map(g => ({
    title: g.title, score: calculateMatchScore(g, company)?.score
  })))

Check why the filter isn't excluding these items. Common causes:
- The deadlinesNext7Days items from stats API are {id, title, deadline, sourceName} 
  objects — they don't have the full grant data needed for calculateMatchScore
- The filter might be finding the wrong grant in the allGrants array
- calculateMatchScore might be returning undefined for these grants

Fix: Instead of filtering deadlinesNext7Days from stats, build the deadline 
widget from the already-loaded grants array (which has full data):
  const urgentDeadlineGrants = (grants as Grant[])
    .filter(g => {
      if (!g.deadline) return false;
      const daysLeft = differenceInDays(new Date(g.deadline), new Date());
      return daysLeft >= 0 && daysLeft <= 7;
    })
    .map(g => ({ ...g, matchScore: calculateMatchScore(g, company)?.score ?? 0 }))
    .filter(g => !company || g.matchScore >= 30)
    .sort((a, b) => new Date(a.deadline!).getTime() - new Date(b.deadline!).getTime())
    .slice(0, 5);

Replace both the "Deadline inom 7 dagar" AND "Deadline snart" sections 
with this urgentDeadlineGrants array.
